Ancestry

The fork stands on a specialized Ampere base.

The pinned foundation is haosdent/vllm@12810046c, itself based on upstream commit 62195e978. Whamp’s work extends that base rather than claiming to originate every DeepSeek V4 Ampere mechanism.

Inherited foundation

DeepSeek V4 sparse MLA on SM8x

Model dispatch, heterogeneous compressed caches, sparse indexer handling, and Ampere-compatible attention paths made the model executable on SM80/SM86.

Inherited execution model

Breakable CUDA graphs

The base captures graph-compatible segments around eager attention and indexer breaks. On server60, this was the largest measured single speed move: 4.96 → 60.27 decode tok/s.

Inherited optional backend

Hierarchical all-reduce

The base carried the 2-island PCIe backend. Whamp added dispatch proof and enabled it only after Nsight and local numerical/latency gates justified the move.

Boundary: the base commit reports A100-specific improvements, exact top-k work, hot-path trims, chunk sharding, and kernel tuning. This report does not transfer its A100 performance numbers to RTX 3090. Only server60 measurements below support server60 claims.

Causal deep dives

What each retained move changes.

Every accepted move had a precondition, direct mediator, fallback or scope guard, and end-to-end check. The system did not keep settings merely because they sounded fast.

Artifact contract exercised by this stack: every routed w2 uses group 128; layers 26 and 37–42 upgrade w2 to W4. Routed w13 uses group 128 on 7 layers, group 256 on 10 layers, and group 512 on 26 layers. MTP is omitted. The remaining non-routed tensors keep source-compatible higher precision. This is the concrete mixed-bit, mixed-group layout behind the results—not a generic claim about every WNA16 checkpoint.
1 · Representation

Low-bit routed experts fit and execute on Humming

Routed experts account for 97.43% of the model’s base parameters. The fork reads packed W2/W4 compressed-tensors, retains projection-specific schemas, and converts them into Humming’s indexed-MoE format after loading. Ordinary attention and shared linears stay on native DeepSeek block-FP8 paths rather than a generic transformed layout.

2 · Frequency

Breakable CUDA graphs remove repeated launch work

The original correctness run used --enforce-eager. Removing it lets the DeepSeek-specific graph system capture compatible segments around eager breaks. A matched A/B raised decode from 4.96 to 60.27 tok/s—about 12.2×—without changing model weights.

3 · Residency

RoPE rows follow served context, not model maximum

Two FP32 RoPE/indexer tables had been materialized for 1,048,576 positions. The patch bounds rows to runtime max_model_len while preserving YaRN frequencies. At the prior 215K profile, this reclaimed roughly 407 MiB per rank.

4 · Representation + execution

Marlin consumes wo_a without a BF16 duplicate

The old path retained one 16 MiB BF16 projection per layer: 688 MiB per rank. Recomputing dequantization saved memory but cut decode to 34.01 tok/s. The retained path keeps FP8 weights, uses Marlin, and selects diagonal group outputs, reaching 230K context at the original ~62 tok/s.

5 · Kernel specialization

FlashMLA replaces only sparse decode

The opt-in AppMana operator consumes the existing 584-byte fp8_ds_mla cache row, so persistent KV format does not change. Seventeen numerical/adversarial tests and seven sm_86 cubins cleared the gate. Prefill deliberately remains on Triton.

6 · Coordination

Hierarchical all-reduce matches the 2×2 PCIe topology

Nsight assigned at least 17.15% of warmed decode wall time to non-overlapped NCCL. Local BF16 tests showed the hierarchy at 78.54–85.46% of NCCL latency across tested message sizes. Enabling islands 0,1;2,3 raised adjacent decode 61.17 → 65.00 tok/s.

Limits and rejected work

The stack is faster, not magically unconstrained.

The accepted service runs near the physical VRAM boundary. The report keeps unsuccessful arms and unsupported transfers visible so the next optimization starts from evidence rather than folklore.

Retained tradeoffs

Thin VRAM margin. Long-depth validation reached 58 MiB free on the combined arm; the earlier capacity release gate recorded 91–94 MiB. This is below the project’s 1 GiB sustained-agent advisory.
  • Combined prefill measured 3.23% below the adjacent plain baseline; its three samples had 3.8% CV.
  • Two-request validation covers two 90K prompts, not two simultaneous 230K prompts.
  • The 16 GiB KV offload tier is a host eviction safety tier. It is not part of the measured 230K on-GPU speed path.
  • The image and topology are server60-specific. The result does not transfer automatically to stock vLLM or another RTX 3090 host.
